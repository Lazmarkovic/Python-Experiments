# Flower of Life Visualizer

This repository provides a small Tkinter application that visualizes a three-dimensional
"Flower of Life" pattern.  The pattern can be scaled interactively and additional sacred
geometry shapes may be inserted.

## Features

- **Interactive scaling** – drag the red handle to expand or shrink the entire Flower of Life.
- **Additional geometry** – press `t` to add a tetrahedron or `c` to add a cube inside the pattern.

## Running

The application uses only the Python standard library.  Start it with:

```bash
python flower_of_life.py
```

A window will appear displaying the pattern.
